# HHC 串流 — Windows x64 候選版

適用 OBS 32.2.2 x64／Qt 6.11.1。未簽章；各版本實測結果見 docs/reviews，不以 CI 或本機通過代替正式驗收。

## 安裝與操作

關閉 OBS，將候選包的 obs-plugins 與 data 複製到 OBS 目錄，保留結構。背景補傳程式與 Schannel 元件須一起安裝；不要替換 OBS 的 Qt 或 FFmpeg DLL。

在「停駐視窗」啟用 **HHC 串流**。主畫面只有狀態、**開始直播／停止直播**及**設定**，可縮窄至按鈕正常顯示所需寬度；設定會開啟獨立視窗。本機錄影仍由 OBS 原本的「開始錄製／停止錄製」控制。

1. 在設定輸入一次串流金鑰並儲存；金鑰與短效 session 僅存 Windows Credential Manager。之後可於輸入釋放且沒有請求進行時更換；傳送及未完成收尾期間鎖定。
2. 直接直播、預排、標題、縮圖、公開開始／結束及發布全部由網站管理。外掛不選場、不排程、不建立替代場次；平台回傳標題僅供識別。
3. 按 **開始直播** 啟動 HHC 串流輸出。這不等同保證已公開；公開與自動開始策略屬於平台。尚未準備接收時會自動等待，可按停止取消等待。
4. 按 **停止直播** 正常停止 HHC 來源並自動補傳、Stop、seal。Console End 也沿用共同分段邊界自動收尾，不停止 YouTube、OBS 全域串流或本機錄影。

Program 收錄維持 1920×1080、30000/1001 fps、NV12、BT.709／有限範圍、48 kHz 雙聲道及三畫質 NVENC。每次新收錄讀取 OBS 串流音軌：簡易輸出用音軌 1，進階輸出用 AdvOut/TrackIndex；來源音量、靜音與音軌路由由 OBS 混音器控制。不支援以猜測音軌補救無效設定；不會在 NVENC 失敗時切 CPU。已開始／恢復的收錄保留原音軌，不能中途切換。

## 自動恢復

斷線自動重試、更新 session 並補傳原 capture，不切到下一場。需要人工處理的非暫時性錯誤才顯示「重試」。收尾不等於平台 ready 或已發布。

設定中的「管理直播」只是網站捷徑。新版不再提供舊帳號模式恢復入口；歷史素材與 journal 保留在磁碟，不遷移、不丟棄。不要重設平台金鑰來處理斷線，否則可能撤銷舊場恢復權限。

正常退出後背景補傳最多 24 小時，仍受平台期限限制。程序中斷不代表正常結束。移除外掛時保留 queue、journal、設定和原錄影。
